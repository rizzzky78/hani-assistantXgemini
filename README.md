## WhatsApp Bot with Google Gemini AI Integration

This WhatsApp bot is designed to provide both customer and admin functionalities for managing a marketplace. It leverages Google Gemini Generative AI for enhanced user experience and intelligent responses.

### Inputs

The bot responds to various commands and keywords, allowing users to interact with the system. These commands can be categorized into:

* **Admin Commands:** These commands are strictly for administrators and include functionalities like product management, order management, payment moderation, and customer approvals.
* **Customer Commands:** These commands are available to all customers and facilitate actions such as browsing the catalog, searching for products, adding items to the cart, placing orders, uploading payment proof, and accessing purchase history.
* **General Commands:** These commands are accessible to everyone and provide general information like accessing the catalog, contacting the admin, and searching for specific products.
* **Group Commands:** These commands are intended for use within WhatsApp groups.
* **Sticker Commands:** These commands are related to sending and managing stickers.

### Outputs

The bot provides various outputs based on user input. These outputs can include:

* **Catalog (PDF):** Customers can access the product catalog in PDF format.
* **Product Information:** Detailed product information, including price, stock, description, and images, is available upon request.
* **Order Details:** Customers can receive order confirmations, payment codes, and invoices. Admins can access ongoing and completed order details and transaction proofs.
* **Shipping Cost:** Admins can check shipping costs based on location and package weight.
* **Purchase History:** Customers can access their complete purchase history.
* **Admin Contact:** Customers can access the admin's contact information.
* **AI-powered Responses:** Google Gemini AI provides intelligent and context-aware responses to user queries, including product recommendations, health consultations, and general information.

The bot uses a structured data format for handling customer information, product data, order details, payment information, and completed orders. This ensures data consistency and facilitates efficient data processing.
